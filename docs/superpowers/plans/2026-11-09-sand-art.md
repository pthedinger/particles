# Sand Art Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** A real-time circular mixture of freely moving liquids, gas, and grains that responds to rotation and shaking.

**Architecture:** A headless Rust simulation owns flat particle buffers and reusable uniform spatial bins. Position-based density relaxation, contact constraints, phase-aware buoyancy and bounded vessel drag run at a fixed timestep. Bevy/egui renders a reconstructed liquid texture and batched grains; no per-particle ECS entity is required. Keep this boundary suitable for later parallel or GPU execution.

**Tech Stack:** Existing Bevy 0.14.2 and inspector's compatible egui reexport, rand 0.8.5, glam 0.27 already in Cargo.lock.

**Spec:** docs/superpowers/specs/2026-11-09-sand-art-design.md

## Global Constraints

- Preserve existing Cargo.lock changes and src/main.rs contents (archive the current app as examples/legacy.rs); leave a.out and tmp.c alone.
- Target 60 displayed FPS; initially approximately 3,000 particles, future scaling to many more explicitly matters to the user.
- Initial fixed step 1/120 second and at most four catch-up steps per displayed frame; report dropped simulation time.
- Recipes express occupied-area shares, not mass shares. Never silently remove particles or change composition for performance.
- Release physics budget per 1/60 simulated second: median below 8 ms, p95 below 12 ms; record actual results.
- No engine upgrade, chemistry, combustion, thermal modeling, or 3D implementation.

## Review Focus

- Invalid or all-zero recipes, extreme supported radii and non-finite property inputs must be rejected or bounded without erasing a working simulation. Task 1 tests validation and count allocation.
- Dense mixed contacts and repeated shake/rotation must keep particles finite and inside the vessel without count/identity loss. Task 2 stress tests this.
- A light grain in gas must not receive water buoyancy; nearby liquid must exchange the reaction momentum. Task 2 isolates these scenes.
- Pause/resume and a long frame must freeze time or report bounded lag, never cause an input explosion. Task 3 tests the clock and input clamping.
- Resizing, UI input capture and rim dragging must use the actual vessel rectangle and preserve its circular aspect. Task 4 tests coordinate mapping and manually checks input capture.

## Files and ownership

- src/material.rs: phases, editable materials, recipe validation and deterministic count allocation.
- src/simulation.rs: particle state, initialization, spatial bins and physics.
- src/controls.rs: bounded fixed-step clock and coordinate conversion.
- src/benchmark.rs, src/bin/benchmark.rs: repeatable headless workload and timing report.
- src/lib.rs: headless module exports.
- src/main.rs: Bevy startup and application state; src/view.rs: egui controls, interaction, texture/mesh drawing.
- tests/recipe.rs, tests/physics.rs, tests/controls.rs: behavioral checks of those boundaries.
- examples/legacy.rs: exact pre-change main.rs so user edits remain available.
- README.md: purpose, run commands, controls, approximations and measured performance.

## Task 2: Headless multiphase solver and early budget check

**Interfaces:** `Particle { position: Vec2, velocity: Vec2, material: usize, radius: f32 }`; `Simulation::new(&Recipe) -> Result<Self, String>`, `Simulation::step(dt: f32, motion: Motion)`, public particles/materials, `Motion { angular_velocity, shake: Vec2 }`; vessel radius 1.0 in simulation units. Internal masses derive from density and area. `benchmark::run(count: usize, frames: usize) -> String` reports timings and actual count.

- [x] Write tests/physics.rs for deterministic initialization, exact per-material count conservation, containment over 300 driven steps, heavy-solid sinking and light-solid rising in a liquid fixture, absence of liquid buoyancy in gas, and persistence of a settled frictional bed. Validate zero-distance contacts and varied radii with a small stress fixture.
- [x] Run `cargo test --release --test physics --offline`; confirm missing dynamics fails observable assertions.
- [x] Implement reusable spatial bins and neighbor pairs with no truncation, continuous integration, phase-aware buoyancy with equal/opposite reaction, fluid occupancy constraints, compressible cohesive gas, solid contact/friction, boundary projection, and moving-glass drag. Rebuild bins during constraint iterations; bound acceleration and displacement. Initialize with a seeded spatial distribution and relax contacts before playback.
- [x] Add src/benchmark.rs and src/bin/benchmark.rs. Warm up 120 steps; measure 600 frame-equivalents of two substeps separately for settling, rotating and shaking. Report median, p95, maximum and conserved count, not just throughput.
- [x] Run physics tests, full suite, and `cargo run --release --offline --bin benchmark -- 3000 600`. Expected: finite state, invariant counts and target budget; profile and adjust algorithm before UI if it misses. Also measure 1500 and 6000.
- [x] Commit the solver and tests, recording actual results in the progress record.
