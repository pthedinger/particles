# Configurable Vessels Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement inline, with one fresh final reviewer.

**Goal:** Five rotating ready-made vessels with matching physics/rendering at 100k particles.
**Architecture:** Shared signed-distance and normal map generated from Rust geometry; analytical Circle fast path. Recipe stores vessel kind/layout seed; simulation and GPU seed carry immutable geometry. Keep world positions, rotate boundary queries by a per-step pose.
**Tech Stack:** Existing Rust/Bevy/wgpu/WGSL, no added dependencies.
**Spec:** ../specs/2026-11-19-vessels-design.md (user chose ready-made vessels first).

Continue existing branch/check-out; preserve Cargo.lock, a.out and tmp.c. No worktree/merge/push. Preserve particle/material counts and 100,000 default. Vessel changes explicitly reseed; material properties/presets stay independent. Fixed obstacles rotate with vessel; gravity remains in world space. Keep Circle behaviour and tests. Temperature does not change phase.
